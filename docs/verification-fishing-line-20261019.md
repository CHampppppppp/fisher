# 持竿鱼线修复

用户反馈：鱼竿拿出时没有线，仅钓鱼时有线。根因是fishing-line仅在fishing.cast非空时显示。

现复用同一条线：线轮经五个导环到竿梢，idle/charging末段为短垂线；抛出后末端连接原浮漂。跟随鱼竿/相机世界变换，取消后恢复垂线；收起工具、持鱼及未抛竿暂停时隐藏，不新增玩法实体/计时或GPU资源。模拟逻辑不变。

实际验证：
- npm run build通过；保留既有大chunk提示。
- npm test：140/140通过（137既有+3渲染组件测试）。首次组件测试误用slot而非index导致一个测试失败，纠正为公开index并断言动作被接受后，全量通过；未绕过产品断言。
- Chrome原生浏览器2/2通过，1280×720及1920×1080各检查普通入口、test入口的未抛竿/蓄力/抛出/收杆/取消/收起/暂停流程，无页面异常。状态断言与实际截图分别保留，截图核对可见垂线、收杆连接浮漂及暂停无残线。没有以截图代替几何连续/端点/唯一对象断言。
- 既有审查者只读审查本轮TypeScript、组件测试及浏览器脚本，未发现高/中问题；其没有独立跑浏览器。
